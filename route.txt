# translated quests are skipped automatically.
#
# Entry forms:
#   Zone Name                 every Alliance-available quest in that zone
#   Zone Name @ 20            ...up to quest level 20 only (rest comes later in the list)
#   class: Druid @ 20         class quests
#   profession: Cooking       profession quests
#   dungeon: Gnomeregan       dungeon quests (grouped by dungeon, wherever Blizzard filed them)
#   dungeon: Gnomeregan +pre  ...plus every quest that leads into them (prequest chains)
#   other: Seasonal           event / misc categories
#   forever: Name             new WoW Forever content: not in any database yet, so it is
#                             translated after the addon has captured it in game
#
